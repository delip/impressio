Notice to the trade

On the making-ready of a forme

Lock the type in the chase, plane it down, and pull a proof. Where the print is weak, build up the packing with tissue; where it punches, cut it away. A good makeready is felt more than seen.

Use it

import { createSheet, pressElement, typesetTex } from 'impressio';

const sheet = createSheet({ width: 720, height: 440, paper: 'cotton', seed: 7 });

sheet.impress('deep', f => {                       // photopolymer, deep bite, black
  f.text('odile marchetti', 360, 200, { font: 'italic 96px "EB Garamond"', align: 'center' });
});
sheet.impress('blind', f => f.rule(180, 250, 360, 2)); // a second, uninked pass
sheet.impress({ ink: '#7a1f1c', depth: 1 }, f => {     // any CSS colour is an ink
  f.ctx.arc(360, 330, 18, 0, 7); f.ctx.fill();         // any Canvas 2D drawing is a forme
});

document.body.append(sheet.render({ azimuth: 315, elevation: 35 }));

// LaTeX: typeset with MathJax (or your own engine), then lock it up like any other cut
const eq = await typesetTex('e^{i\\pi} + 1 = 0', { size: 48 });
sheet.impress('deep', f => f.cut(eq, 360, 220, { align: 'center' }));

// type and maths together: $inline$ sits on the baseline, $$display$$ takes its own line
const block = await typesetRich('The area is $A = \\pi r^2$ exactly.', { font: '24px "EB Garamond"', maxWidth: 480 });
sheet.impress('deep', f => f.block(block, 40, 60));

// or press real DOM text in place, in whatever fonts your CSS uses:
await pressElement(document.querySelector('.card'), { paper: 'handmade' });
